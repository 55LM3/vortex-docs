# Studio Keybindings

A reference for the keyboard shortcuts and mouse controls in Vortex Studio's editor.

## File

| Shortcut | Action |
| --- | --- |
| `Ctrl` + `S` | Save |

## Editing

| Shortcut | Action |
| --- | --- |
| `Ctrl` + `C` | Copy selected |
| `Ctrl` + `V` | Paste copied parts |
| `Ctrl` + `D` | Duplicate selected nodes/parts |
| `Ctrl` + `G` | Group selected parts into a model |
| `Shift` + `Ctrl` + `G` | Ungroup a model |
| `Ctrl` + `F` | Focus the view on the selected parts |

## Tools

Press a number key to activate the corresponding tool.

| Key | Tool |
| --- | --- |
| `1` | Select mode |
| `2` | Move mode |
| `3` | Rotate mode |
| `4` | Scale mode |

## Camera

| Shortcut | Action |
| --- | --- |
| `W` | Move in the direction you're looking |
| `A` | Move view left |
| `S` | Move in the opposite direction you're looking |
| `D` | Move view right |
| `Q` | Move camera down |
| `E` | Move camera up |
| Scroll wheel | Move the camera toward/away from where the mouse is pointing |
| Hold right-click + drag | Move the view |

## Selection

| Shortcut | Action |
| --- | --- |
| Left-click | Select |
| `Ctrl` + click | Select multiple nodes one at a time |
| `Shift` + click nodes in the Explorer | Select everything in between |

## Window

| Shortcut | Action |
| --- | --- |
| `F11` | Toggle fullscreen |
